02 • System Topology

Engineered for Fault Tolerance & Scale

ARCH • 01

Dual-Execution Strategy

Files under 15MB process directly in the client's browser using WebAssembly and pdf-lib. Large enterprise files automatically stream to the Fastify gateway via signed URLs.

Latency Target < 15ms Client
ARCH • 02

Asynchronous BullMQ Pipeline

Heavy operations are queued into Redis, processed by isolated worker nodes with exponential retry backoff, and automatically cleaned up via a 24-hour TTL cron daemon.

Job Reliability 100% DLQ Recovery
ARCH • 03

Turborepo Orchestration

Unified monorepo boundaries linking web, mobile, API, workers, and shared core packages with cached build pipelines and shared canonical TypeScript contracts.

Package Manager pnpm + Turborepo

05 • Getting Started

Run Locally in Under 3 Minutes

# 1. Clone repository and install dependencies
$ git clone https://github.com/Subhash6102003/pdf-suite-monorepo.git && cd pdf-suite-monorepo && pnpm install
# 2. Start PostgreSQL, Redis & MinIO services via Docker
$ docker compose -f services/workers/docker/docker-compose.dev.yml up -d
# 3. Push database schema & start development cluster
$ pnpm --filter infra db:push && pnpm dev
